# CISD Student Performance

Public SPA comparing Conroe ISD's **District Improvement Plan** goals against the state's
official **TAPR** outcome data — what CISD promised, what CISD claims, and what the data shows.

- **Live:** https://cisd-performance.boardmonitor.app
- **Publishes from:** `docs/` on `main` (GitHub Pages)
- **Part of:** the boardmonitor.app family of independent CISD watchdog sites.

## Structure
```
docs/
  index.html        # single-page app
  styles.css        # design tokens shared with the CISD Hub look
  app.js            # renders docs/data/outcomes.json
  data/outcomes.json# generated by the pipeline publisher
  CNAME             # cisd-performance.boardmonitor.app
```

## Data pipeline
The `outcomes.json` data file is produced on the NAS, not in this repo:
`\\rdn-nas01\document\CISD-Outcomes\pipeline\`

1. `dip_extractor.py`  — extract DIP Goal 1 objectives from the PDFs
2. `metric_mapper.py`  — classify objectives into canonical metrics (TAPR-mappable vs internal)
3. `tapr_loader.py`    — join TEA TAPR actuals, compute met/missed
4. `site_publisher.py` — emit `docs/data/outcomes.json` into this repo

Every published number traces to a source: DIP targets cite the source PDF + page;
actuals come from the named TEA TAPR file + column.
